# 오늘의 블로그 글

**오늘의 글 만들기 → 완성 원고 읽기 → 승인 또는 보류 → 제목·본문 복사** 흐름으로 바꿨습니다.
CSV와 빈칸 채우기는 기본 화면에 나타나지 않습니다.

- 네이버 검색광고 연관 키워드의 월 검색량을 조회합니다.
- 분야 관련 후보 중 검색량 상위 최대 5개를 데이터랩 최근 12개월 추세와 비교합니다.
- 가중치 점수로 주제를 고르고 이미 작성한 주제는 제외합니다.
- OpenAI 웹 검색으로 근거를 조사한 뒤 네이버·티스토리 원고를 각각 집필합니다.
- 원고를 승인하면 제목과 평문 본문을 별도로 복사할 수 있습니다. 승인 후 수정하면 재검토합니다.
- 직접 발행은 하지 않습니다.

## 처음 열기

이 버전이 있는 브랜치에서 **Code → Codespaces → Create codespace**를 누르세요.
새 Codespace는 앱을 자동 실행하고 8501 포트를 브라우저로 엽니다. 포트는 **Private**로 유지하세요.
자동으로 열리지 않으면 Ports에서 8501의 브라우저 아이콘을 누릅니다.

이미 열어 둔 Codespace는 코드 업데이트와 컨테이너 재빌드 후 새 시작 설정이 적용됩니다.
기존 프로세스가 있다면 한 번 종료하고 다시 시작하세요. 수동 실행은 아래와 같습니다.

```bash
python -m pip install -e '.[dashboard]'
streamlit run app.py
```

## 실제 조사와 예시의 차이

API 연결 전에는 **완성 글 예시 보기**를 누르세요. 읽을 수 있는 완성 글 2편이 있으며,
검색량을 측정한 결과나 AI 조사 결과로 표시하지 않습니다.

**실제 검색 분석·AI 집필에는 네이버와 OpenAI 키를 한 번 연결해야 합니다.**
[연결 방법과 사용법](docs/writing-desk.md)을 따라 설정하면 “오늘의 글 만들기”를 사용할 수 있습니다.
이번 변경은 모의 API 응답과 화면 테스트로 검증하며 실계정 유료 호출은 실행하지 않았습니다.
API 인증·계정별 한도·검색 도구 지원은 최초 연결 시 확인해야 합니다.

조회수나 수익은 보장하지 않습니다. 검색량은 검색 횟수이며 내 블로그의 예상 방문자 수가 아닙니다.
검색 API가 응답한 특정 분야 후보 내 비교이며 전체 검색시장 최고 키워드를 주장하지 않습니다.

## 검토와 복사

1. “이 주제를 고른 이유 · 자료 확인”에서 선정 이유와 출처를 살펴봅니다.
2. 원고를 읽고 출처·핵심 사실·플랫폼별 차이를 확인합니다.
3. **이 글 승인** 또는 **지금은 보류**를 선택합니다.
4. **발행할 글**에서 **제목 복사**, **본문 전체 복사**를 누릅니다.
5. 블로그 편집기에 붙여넣고 직접 발행합니다. 사진과 서식은 필요에 따라 추가하세요.

복사 기능이 브라우저 정책으로 차단되면 아래 텍스트를 길게 눌러 복사하거나 TXT로 저장할 수 있습니다.
기기별 클립보드 권한과 실제 네이버·티스토리 붙여넣기는 실기기 확인이 필요합니다.
이 예시에는 개인정보·API 키·검토용 메모를 본문에 넣지 않습니다.

## 저장·비용·실행 제한

로컬 SQLite 또는 같은 비공개 Codespace에 상태를 저장합니다. Codespace 삭제 전 DB를 백업하세요.
공개 배포는 계속 차단되며 PostgreSQL/OIDC 연결은 별도 단계입니다.
GitHub Actions 임시 디스크에는 운영 데이터를 보관하지 않습니다.

실행당 네이버 요청 최대 2회, AI 요청 최대 2회, 조사용 웹 검색 최대 2회, 자동 재시도 0회입니다.
같은 날 같은 분야의 성공 결과는 재사용하고 진행 중/실패한 작업은 재호출하지 않습니다.
실행당 USD 0.50의 **추정 예산**을 예약하고 일일 USD 2.00 또는 4회에서 차단합니다.
실패 시에도 예약을 유지합니다. 이 금액은 실제 청구액 또는 청구 보장 상한이 아닙니다.
공급자 가격·검색 비용에 따라 달라지므로 OpenAI 프로젝트 예산/알림을 별도로 설정하세요.

## 개발·테스트

```bash
python -m pip install -e '.[dashboard]'
python -m unittest discover -s tests -v
python -m compileall -q src app.py legacy_app.py tests
```

실제 API 호출 없이 fixture와 Streamlit AppTest를 실행합니다.
기존 CSV MVP와 CLI는 유지됩니다. 기존 편집기는 `streamlit run legacy_app.py`로 열 수 있습니다.
[기존 CSV 사용 설명](docs/mvp-v1.md)과 [초기 아키텍처](docs/architecture.md)는 v0.1 기록입니다.
현재 구현 범위와 제한은 이 README 및 [새 작업실 안내](docs/writing-desk.md)를 우선 참고하세요.
